# Frontend NWB Asset

Target folder: `frontend/`

Esta pasta concentra os clientes do sistema:

- `web/`: painel administrativo em Next.js.
- `mobile/`: aplicativo de inventario em React Native + Expo.

## Comandos legados (a partir de `frontend/`)

- `npm run dev` -> sobe o frontend web (`frontend/web`)
- `npm run build` -> build do frontend web
- `npm run start` -> start do build web
- `npm run dev:mobile` -> inicia Expo do mobile

## API alvo

Os dois clientes consomem o backend Laravel em `backend/`.
