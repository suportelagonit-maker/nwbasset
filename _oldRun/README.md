# NWB Asset Workspace

Repositorio reorganizado por area de entrega:

- `backend/`: API e dominio em Laravel.
- `frontend-web/`: painel web em Next.js.
- `frontend-mobile/`: app mobile em React Native + Expo.
- raiz: scripts de orquestracao e documentacao compartilhada.

## Start rapido (scripts na raiz)

- Backend + frontend web:
  - `.\start-nwbasset.ps1`
- Somente backend:
  - `.\start-api.ps1`

Atalhos `.cmd` tambem ficam na raiz.
